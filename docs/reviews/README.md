# BioChoco data-quality reviews

Monthly critical reviews of BioChoco deployment data status, generated by the
`biochoco-data-review` Claude Code skill.

## Run it

```
/biochoco-data-review
```

The skill triggers the `/api/cron/biochoco-review` route in **production**
(via `scripts/run-biochoco-review.mjs` inside the container over SSH), which runs
the data-quality checks against the nightly-refreshed Drive counts and returns
JSON. The skill then writes a Spanish report here as `<YYYY-MM>-biochoco-review.md`.

> The route must be **deployed** (`./deploy.sh`) before the skill can run in prod.
> `scripts/biochoco-review-snapshot.ts` is a local/dev runner (tsx, writes a JSON
> file) for working against a local DB.

- **Reports** (`*-biochoco-review.md`) are committed — they're the historical record.
- **Snapshots** (the raw JSON evidence) are written to `data/reviews/` which is
  gitignored.

What it checks, the architecture, and the design decisions are documented in
`docs/plans/2026-06-16-feat-biochoco-data-quality-review-skill-plan.md`.
